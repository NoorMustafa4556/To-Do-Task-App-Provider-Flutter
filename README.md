# 📝 Flutter To-Do Task App (Provider + SQLlite)

A **feature-rich offline To-Do List application** built with Flutter, using **Provider** for state management and **SQFlite** for local storage. Designed with **clean architecture** principles to ensure scalability, maintainability, and easy debugging.

---

## 🎯 Overview
This app is more than just a utility — it’s a **practical learning project** for developers.  
The codebase is organized around **Separation of Concerns**, keeping:
- **UI Layer** – Purely for rendering visuals.
- **Business Logic Layer** – Managed through Provider.
- **Data Layer** – Handled by SQFlite for persistence.

---

## ✨ Features
- **State Management** – Powered by `provider` for reactive updates.
- **Local Storage** – Save tasks offline with `sqflite` (SQLite).
- **Full CRUD** – Create, Read, Update, and Delete tasks.
- **Organized View** – `TabBar` to switch between **Pending** & **Completed** tasks.
- **Dedicated Add/Edit Screens** – Simplified user flow.
- **Due Date Picker** – Native date picker with formatted date via `intl`.
- **Modern UI** – Custom form fields, buttons, and responsive design.
- **Safety** – Confirmation dialog before deleting tasks.

## 🛠️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You need to have the Flutter SDK installed on your machine.
- [Flutter Installation Guide](https://flutter.dev/docs/get-started/install)

### Installation

## 1.  Clone the repository:
    ```sh
    git clone https://github.com/NoorMustafa4556/To-Do-Task-App-Provider-Flutter.git


## 2.  Navigate to the project directory:
    ```sh
    cd To-Do-Task-App-Provider-Flutter
    ```
## 3.  Install the dependencies:
    ```sh
    flutter pub get
    ```
  ## 4.  Run the app:
    ```sh
    flutter run
    ```

   ## 📦 Main Packages Used

-   **provider:** For state management.

-   **sqflite** – Local storage (SQLite).

-   **path** – For database path.

-   **intl** – Date formatting.

-   **fluttertoast** – Notifications.

-   **flutter_spinkit** – Loading indicators.
